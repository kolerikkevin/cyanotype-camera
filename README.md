# cyanotype camera

A webcam that exposes cyanotype prints in the browser. Expose, wash, save a 4:5 print.

**Use it:** https://kolerikkevin.github.io/cyanotype-camera/

- On a computer: portrait, negative or shadow, clean or brushed coating.
- On a phone you land on `phone.html` (front and back camera). `?desktop` keeps the computer version.
- Everything runs in your browser. Nothing is uploaded.
